# Papers

This folder contains the generated paper index.

- `papers.tsv`: machine-readable table generated from `bibliography/references.bib`.
- `paper_list.md`: categorized Markdown list for GitHub browsing.
- `link_check.tsv`: direct-link verification report generated by `tools/verify_links.py`.

## Link Source

The `link_source` column has the following meanings:

- `doi`: direct DOI link from an explicit BibTeX `doi` field.
- `arxiv`: direct arXiv link from an explicit `note={arXiv:...}` field.
- `url`: direct URL from an explicit BibTeX `url` field.
- `needs_direct_link`: no DOI, arXiv ID, or URL is present in the source BibTeX. The generated Scholar query is search-only and is not treated as a verified paper/project link.
